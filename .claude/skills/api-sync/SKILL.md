# /api-sync [--write] [--url <backend-origin>]

Detect drift between four things:
1. **Live schema:** `<backend>/api/schema/`, generated by drf-spectacular.
2. **Generated types:** `src/api/schema.d.ts` (committed, never hand-edited).
3. **Contract copy:** `docs/03-api-contract.md` in this repo.
4. **Contract source:** `../../django_api_project/docs/03-api-contract.md` (the backend wins).

## Steps

1. **Pick the schema source**, first one that works:
   - `--url <origin>` if given;
   - the local backend: `curl -s -m 5 http://127.0.0.1:8000/api/health/` returns `{"status":"ok"}`;
   - otherwise ask the user to start it (`cd ../../django_api_project && uv run python manage.py runserver`) or to give the production URL. Warn that a sleeping Render instance can take ~1 minute to answer.
   Never fall back to guessing the schema.
2. **Generate** into the scratchpad: `npx openapi-typescript <origin>/api/schema/ -o <scratchpad>/schema.d.ts`. If it fails, report the error and stop.
3. **Diff the types.** Compare `<scratchpad>/schema.d.ts` with `src/api/schema.d.ts` (`git diff --no-index --stat`, then the content). Summarise as: added/removed paths, added/removed/changed fields per schema component. Don't paste the whole file.
4. **Watch for known transitions**, and say which frontend code they affect:
   - list responses changed from an array to `{count, next, previous, results}` → backend #11 landed. `src/api/pagination.ts` should now pass `?page=`/`?page_size=` to the server; open a frontend issue to switch.
   - `search` / `author` query parameters appeared on list operations → search/filter can leave the stretch list.
   - a field renamed or removed on `User`/`Blog` → list the components that read it (Grep `src/`).
5. **Diff the contract docs.** `git diff --no-index docs/03-api-contract.md ../../django_api_project/docs/03-api-contract.md`. Report whether the copy is stale. If the backend repo isn't there, say so and skip.
6. **Report** in ≤15 lines: `IN SYNC`, or a list of drift items, each with the frontend files affected and the backend issue it belongs to if known.

## With `--write`

After the report:
- `npm run gen:api -- <origin>` (or copy `<scratchpad>/schema.d.ts` over `src/api/schema.d.ts` with `cp`, since the hook blocks the Edit/Write tools on that file);
- copy the backend's `03-api-contract.md` over `docs/03-api-contract.md` if it changed;
- run `npm run typecheck` and list every new error as `file:line — message`. Don't fix them here; suggest `/issue` or the open issue they belong to.

Never edit the backend repo.
